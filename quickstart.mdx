Google's unified API surface gives you programmatic access to the full suite of Google cloud services — from storage and compute to identity and productivity tools. This guide walks you through the fastest path to your first successful API call.

<Steps>

  <Step title="Sign in or create a Google account">
    Head to [accounts.google.com](https://accounts.google.com) and sign in with your existing Google account. If you don't have one yet, click **Create account** and follow the prompts to register with your email address.

    <Note>
      Use a dedicated work or project account when building production integrations. This makes it easier to manage permissions and transfer ownership later.
    </Note>
  </Step>

  <Step title="Navigate to API settings and generate an API key">
    Once signed in, open the [Google API Console](https://console.developers.google.com) and follow these steps:

    1. Select or create a **Project** from the top navigation bar.
    2. In the left sidebar, go to **APIs & Services → Credentials**.
    3. Click **+ Create Credentials** and select **API key**.
    4. Copy the generated key and store it securely — you will not be shown it again in full.

    <Warning>
      Never commit your API key to source control or expose it in client-side code. Use environment variables or a secrets manager to keep it safe.
    </Warning>
  </Step>

  <Step title="Make a test request">
    With your API key in hand, run the following `curl` command in your terminal. Replace `YOUR_API_KEY` with the key you generated in the previous step.

    ```bash
    curl --request GET \
      --url https://api.google.com/v1/resources \
      --header "Authorization: Bearer YOUR_API_KEY" \
      --header "Accept: application/json"
    ```

    A successful request returns an HTTP `200 OK` status alongside a JSON payload.
  </Step>

  <Step title="Parse the JSON response">
    The API responds with a structured JSON object. Here is an example response to help you understand the shape of the data:

    ```json
    {
      "status": "ok",
      "data": {
        "resources": [
          {
            "id": "res_01HXYZ123456",
            "name": "My First Resource",
            "type": "storage",
            "created_at": "2024-06-01T10:00:00Z",
            "status": "active"
          },
          {
            "id": "res_01HXYZ789012",
            "name": "Secondary Resource",
            "type": "compute",
            "created_at": "2024-06-02T08:30:00Z",
            "status": "active"
          }
        ],
        "total": 2,
        "page": 1,
        "per_page": 20
      }
    }
    ```

    Key fields to note:

    | Field | Type | Description |
    |---|---|---|
    | `data.resources` | array | List of resource objects belonging to your account |
    | `data.total` | integer | Total number of resources across all pages |
    | `data.page` | integer | Current page number in the paginated response |
    | `id` | string | Unique identifier for each resource — use this in subsequent API calls |

    <Tip>
      Use a tool like [jq](https://jqlang.github.io/jq/) to pretty-print and filter JSON responses directly in your terminal: `curl ... | jq '.data.resources'`
    </Tip>
  </Step>

</Steps>
